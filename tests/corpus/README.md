# Corpus

Asset catalogs compiled by Apple's actool (Xcode 26.2 – 27.1), taken from open-source projects at
the commit or release listed, with the inputs they were compiled from where those are public.
Each file stays under its project's licence; the icons are those projects' marks and are here
only to test accord against Apple's output.

Binaries are in Git LFS: run `git lfs pull` after cloning. `corpus.toml` has each file's exact
origin and the compile arguments of the pairs.
